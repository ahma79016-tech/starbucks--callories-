# Starbucks Calories Prediction App ☕🔥

Yeh ek complete Machine Learning Web App hai jo Starbucks drinks ki nutritional value (Sugar, Fat, Caffeine, Category, Size) ki buniyad par **Calories** predict karti hai.

## 📂 Project Structure
- `app.py`: Streamlit Calories Prediction Dashboard & Visualizations.
- `train_model.py`: Decision Tree Calories Regressor Model Training Script.
- `decision_tree_calories_model.pkl`: Trained Calories Decision Tree Model.
- `model_columns.pkl`: Saved Features Structure.
- `Starbucks_Dataset.csv`: Actual Starbucks Dataset.
- `requirements.txt`: Streamlit Deployment Requirements.

## 🚀 Streamlit Cloud Deployment Steps
1. Is ZIP ko Unzip karein aur tamam files ko apne GitHub repository me push karein.
2. [share.streamlit.io](https://share.streamlit.io/) par ja kar new app banayein.
3. Main file `app.py` set karke Deploy kar dein!
